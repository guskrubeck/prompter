Prompter de Bolso

Seguir minha voz: o texto anda quando você fala e para quando você para. Precisa de internet e de permissão para o microfone.

No palco: toque na tela para pausar ou continuar. Arraste para cima ou para baixo para ajustar a posição. Com teclado ou controle Bluetooth: espaço pausa, setas mudam a velocidade, Page Up/Down pulam uma tela, Esc volta.
